MakerWorld Extension Setup

Follow the exact click-by-click steps below. Pick your OS first, then do each step in order.

Windows

Exactly what to click (Windows)

  1. Click Download for Windows below and extract the ZIP file.
  2. Open Chrome and click the address bar, type chrome://extensions, then press Enter.
  3. On the Extensions page, turn on Developer mode (top-right toggle).
  4. Click Load unpacked.
  5. Select the extracted makerworld_capture_extension folder, then click Select Folder.
  6. Open PowerShell in your project folder and run bootstrap_extension_setup.ps1.
  7. Enter your DATABASE_URL (and EXTENSION_API_KEY if requested), then wait for completion.
  8. Click the extension icon in Chrome, log in, then open MakerWorld and press Q while hovering a model.
macOS

Exactly what to click (macOS)

  1. Click Download for macOS below and extract the ZIP file.
  2. Open Chrome and go to chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked.
  5. Select makerworld_capture_extension from the extracted folder.
  6. In Terminal, run bootstrap_extension_setup.sh to configure startup and environment values.
  7. Open the extension popup and sign in.
  8. Open MakerWorld and press Q while hovering a model card.
Chromebook

Exactly what to click (Chromebook)

  1. Click Download for Chromebook below and extract the ZIP file.
  2. Open Chrome and go to chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked.
  5. Select makerworld_capture_extension from the extracted folder.
  6. Click the extension icon and choose hosted website mode.
  7. Click Open Web Portal and log in to continue ordering.

Portal: print-portal-qm9p.onrender.com
